# ThinkCart policy: Returns and return window
- Return window: 7 days from the delivery date. Item must be unused, with original tags and packaging.
- Non-returnable items: innerwear, perishables, gift cards, personal care items with a broken seal, and Final Sale items.
- Damaged or wrong item: report within 48 hours of delivery with a photo; always accepted, no pickup charge.
- Free return pickup for orders above ₹499; otherwise a ₹49 pickup fee is deducted from the refund.
